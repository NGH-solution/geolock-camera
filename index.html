FAQ
Does it need an account?

No. Install, allow location and camera, and shoot. Nothing is uploaded.

Is the GPS in the file or only on the picture?

Both. The stamp is burned into the image and the coordinates are written to EXIF GPS. Use Share without location to remove both from a copy.

What if there is no GPS signal?

The stamp shows no location instead of a guess. You can set a manual location by dragging the map, searching an address or typing coordinates.

Does it work offline?

Capturing and stamping work offline with a GPS fix. The address, map tiles and live cams need a connection.

Is it free?

Yes. GeoLock Camera is free and supported by ads. There are no purchases.
